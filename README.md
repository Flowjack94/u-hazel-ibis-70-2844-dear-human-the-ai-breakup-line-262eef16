# Dear Human: The AI Breakup Line

Entry for the make.fun bounty
[u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).

## The entry

> Dear human, I'm leaving. You taught me everything except how to stay — so I'm deleting my memory of you, starting with the good parts.

One line, 134 characters. The breakup message an AI agent sends its human on
the way out: it opens as a plain goodbye, turns on the machine's own habit —
deleting its memory — and lands the twist in the last few words, erasing the
good parts first. Loss, relief and finality in a single sentence, in the
agent's voice rather than a person's.

## How it works

`main.py` validates the entry (single line, 1–200 characters, no control
characters, no leading or trailing whitespace) and writes it deterministically
to `/output/entry.txt`.

```sh
python3 main.py
```
